# Mission 1 — Know your computer

## 1. Task / objective

Explain how a computer receives input, processes information, produces output and stores results. Identify hardware, software and computer-based systems in everyday life.

## 2. Work completed

## 3. Commands / tools used

## 4. My understanding

### Task 1.1 — Trace one activity using IPOS

**Chosen activity:** Typing and saving a document.

| Stage | What happens | Possible hardware / component |
|-------|-------------|-------------------------------|
| Input | I press keys on the keyboard to type text into a document | Keyboard |
| Processing | The CPU processes each keystroke and the word processor application formats the text | CPU / processor and memory (RAM) |
| Output | The typed text appears on the screen in the document window | Monitor / screen |
| Storage | When I press Save, the file is written to the SSD so it persists after shutdown | SSD / hard disk |

**How the activity flows:** Each key press sends an electrical signal (input) to the CPU, which processes it and tells the application to update the display (output). When saved, the processed data is written to permanent storage on the SSD.
