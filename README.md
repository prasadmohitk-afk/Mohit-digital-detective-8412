# The Digital Detective — Diwali Independent Learning Assignment

## About this project

This repository contains my work for the **Digital Detective** assignment, a hands-on exploration of how computers work. The assignment is organised into nine missions (Mission 0–8), each focusing on a different aspect of computing — from hardware basics and terminal commands to number systems, Git workflows, and networking.

Each mission was completed in order, documented in its own folder with a README, and committed separately.

## Topics explored

- Input, Processing, Output, Storage (IPOS)
- Hardware vs software classification
- Terminal commands (`pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `cat`)
- Flags, pipes and package managers
- Operating system responsibilities, processes, paths and permissions
- Compilers vs interpreters
- Decimal, binary and hexadecimal number conversions
- ASCII and UTF-8 text encoding
- Git workflow: staging, committing, branching, Pull Requests
- LAN, MAN, WAN, DNS, routers, protocols, packet switching, client-server model

## Running the number converter

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

The program asks you to enter a decimal number, then displays its binary and hexadecimal equivalents.

## Learning summary

Through this assignment I gained practical experience with the terminal, understood how the OS manages resources and permissions, learned how numbers and text are stored in binary, built a small Python converter, and practised the full Git collaboration workflow including branches and Pull Requests. Each mission deepened my understanding of a different layer of computing.
